## 🚀 Core Specializations & Focus Areas

*   **🚁 Autonomous Flight Systems**
    *   Developing robust autonomous flight logic, sensor fusion algorithms, and low-latency flight controls for custom unmanned aerial vehicles (UAVs).
*   **⚡ Hardware Acceleration & RTL Design**
    *   Offloading critical, high-computation robotics loops (like computer vision pipelines or matrix math) from processors into dedicated FPGA Programmable Logic fabric to bypass CPU performance bottlenecks.
*   **🧠 Intelligent Cyber-Physical Systems**
    *   Bridging the gap between modern artificial intelligence models and constrained physical edge computing systems.
